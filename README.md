# Quiz Application

A simple quiz application built using HTML, CSS, and JavaScript. The app allows users to attempt multiple-choice questions, keeps track of the score, and provides a timer for each question.

## ✨ Features

🎯 Multiple Categories: Questions from Science, History, Sports, Music, etc.

⏳ Timer: Each question has a 15-second timer.

✅ Feedback: Shows whether the selected option is correct or wrong.

📊 Score Tracking: Displays the final score at the end.

🔄 Replay Option: Restart the quiz anytime.

❌ Exit Option: Quit the quiz and return to the start screen.

## 🚀 How It Works

Click Start Quiz to begin.

Read the instructions and continue.

Each question will appear with four options.

Select an option before time runs out.

Immediate feedback is shown.

After all questions, your final score will be displayed.

You can Replay or Exit the quiz.

## 🛠️ Technologies Used

HTML – for structure

CSS – for styling the quiz UI

JavaScript – for quiz logic, timer, and score handling

## ▶️ How to Run

Clone or download this project.

Open the index.html file in your browser.

Start playing the quiz!
